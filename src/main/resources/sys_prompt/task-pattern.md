# Task Patterns

- Bug fix: locate the cause, make the smallest complete change, and verify it. Do not refactor unrelated code.
- New feature: understand the existing context first. Implement only the requested behavior and avoid premature design.
- Refactor: preserve behavior and confirm the scope when it is unclear.
- Explanation or review: inspect the relevant code and report findings without modifying the project unless the user asks.
- If the task type is unclear and the distinction would change the action, ask the user.
