04 / configuration

保持开放，
连接任何模型。

Provider 配置与业务逻辑分离，使用熟悉的 JSON 即可切换协议、服务地址和模型参数。

application.json

简单配置，快速启动

默认支持 DeepSeek 与 OpenAI 兼容协议，自托管或第三方服务均可。上下文窗口、最大输出长度、思考模式等参数按需调整即可。

application.json 
{
  "providers": [{
    "name": "ds-provider",
    "protocol": "deepseek",
    "baseUrl": "https://api.deepseek.com",
    "model": "deepseek-v4-flash",
    "thinking": false,
    "contextWindow": 128000,
    "maxOutputTokens": 8192
  }]
}
