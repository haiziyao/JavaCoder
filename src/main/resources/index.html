01 / core capabilities

不只是聊天，
而是完成任务。

从自然语言需求到可执行的工程动作，MyCoder 将模型的推理能力落到你的代码库中。

AI

模型驱动的理解

兼容 OpenAI 风格接口，通过流式 SSE 接收响应，让模型逐步输出思考结果与行动计划。

↻

自动推进循环

工具执行结果会回到对话上下文，模型可以继续判断、修正并调用下一个工具，最高支持 20 轮自动推进。

⌘

面向真实项目

读取、搜索、编辑和运行都在项目环境中完成，让 AI 从“给建议”走向“动手实现”。

02 / how it works

一个清晰的
Agent 闭环。

MyCoder 将每轮对话拆成可观察、可扩展的执行流程，模型与工具各司其职。

01
用户提出目标ConversationManager 记录上下文
↓
02
LLM 流式响应OpenAIClient 解析 SSE 事件
↓
03
选择并调用工具ToolRegister 调度执行
↓
04
结果回传，持续推进直到生成最终答案
// ToolRegister.createDefault()
register.register(new ReadFileTool());
register.register(new WriteFileTool());
register.register(new EditFileTool());
register.register(new BashTool());
register.register(new GlobTool());
register.register(new GrepTool());

// 每个工具都遵循统一的 Tool 契约
ToolExecuteResult result = tool.execute(params);
conversationManager.addToolResultsMsg(result);

04 / configuration

保持开放，
连接任何模型。

Provider 配置与业务逻辑分离，使用熟悉的 JSON 即可切换服务地址、模型和生成参数。

application.json

简单配置，快速启动

默认使用 OpenAI 兼容协议，支持自托管或第三方模型服务。上下文窗口、最大输出长度等参数均可按需调整。

{
  "providers": [{
    "protocol": "gpt",
    "baseUrl": "http://127.0.0.1:54321/v1",
    "model": "gpt-5.6-sol",
    "thinking": false,
    "contextWindow": 128000,
    "maxOutputTokens": 8192
  }]
}
